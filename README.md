# AI_1C harness

Живой канон ИИ-разработки **1С** (не zip-kit). Версия базы: см. `VERSION` (из пакета Energy kit).

## Состав

| Путь | Содержание |
|------|------------|
| `AGENTS.md` | Обязательные правила агента |
| `START_PROMPT.md` | Стартовый промпт |
| `rules\` | rules-1c (платформа / процессы) |
| `skills\` | навыки 1c-*, cfe-*, db-*, epf-* |
| `docs\` | 01…10 (MCP, Vanessa, команда на серверах, …) |
| `scripts\`, `tools\`, `mcp\`, `tests\`, `tasks\` | обвязка из комплекта |
| `config\project.env.example` | пример env **без секретов** |

Отдельной папки `kit\` нет: этот каталог и есть канон. Архив для передачи — при необходимости собрать скриптом позже.

## Подключение проекта

В папке контура (`..\projects\<имя>\`) файл `PROJECT.md` указывает сюда:

- правила: `F:\AI_1C\harness\AGENTS.md` + `rules\`
- skills: `F:\AI_1C\harness\skills\`
- docs: `F:\AI_1C\harness\docs\`

Адаптер IDE (Claude/Cursor) читает те же пути; секреты — только в `project.env.local` **проекта**, не в харнесе.

Репозиторий инициализирован в этом каталоге (`main`). Remote — по решению владельца.
