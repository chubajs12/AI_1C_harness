# Делегирование 1С-задач в Harness

В Claude-контуре роли лежали в `<проект>\.claude\agents\*.md` (15 файлов). В Harness роль не отдельный агент —
это промпт субагента. Роль задаётся ссылкой на файл, а не пересказом.

## Когда делегировать

- **quick-fix** (одно логическое изменение в одном модуле, ≤ `QUICKFIX_MAX_LINES` из `.dev.env`, по умолчанию 40 строк)
  и **docs-fix** — родитель делает сам. Делить нечего.
- **full-cycle** (больше одного модуля, метаданные, архитектура, нетривиальный баг) — делегировать, если задача
  объёмная по чтению/правке. Триггеры полного цикла в любом размере: транзакции/проведение, публичные контракты,
  связанные метаданные, заимствованные объекты расширения, RLS/роли, подписки, регламентные задания.
- Параллелить 1С-работу **запрещено по умолчанию**: метаданные плотно перекрёстно связаны, параллельные агенты
  ломают GUID и ссылки. Параллельно — только доказуемо независимые куски (новая обработка + новая функция общего
  модуля без общих метаданных).

## Как звать

```
subagent(prompt:
  Роль: <роль>. Прочитай <проект>/.claude/agents/<роль>.md и действуй строго по нему,
  вместе с .claude/rules-1c/subagent-core.md и правилами проекта (CLAUDE.md).
  Задача: ...
  ## Upstream Handoff
  <блок предыдущей стадии дословно, если он есть>
  Ограничения: ...
)
```

- Файл роли читается субагентом из рабочей папки проекта — путь давать абсолютный или от корня проекта.
- Handoff передаётся **дословно**, без пересказа: пересказ — главный источник расхождений между стадиями.
- Свои добавки (новые ограничения, правки пользователя) — отдельным разделом **после** `## Upstream Handoff`.
- Handoff должен перечислять артефакты и публичную поверхность, а не «см. файлы выше»; такой Handoff отклонять.

## Что субагент обязан вернуть

- Список изменённых файлов и что именно изменено (по файлам), против плана.
- Результаты валидаторов с отпечатками состояния (`syntaxcheck` → `check_1c_code` → `review_1c_code`, `verify_xml`).
- Найденные рядом дефекты — сообщить, не чинить (вне плана).
- Если план неверен — `CONFUSION` наверх, а не переписывание плана.

## Гейты

Субагент наследует гейты проекта: `.claude/rules-1c/verification-gates.md`, `verification-policy.md`,
`subagent-core.md`. Родитель не принимает «сделано» без свежих доказательств и сам проходит стадии 4a/4b/5
(см. навык `1c-pipeline`).
