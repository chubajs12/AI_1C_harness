# /erf-bsp-init — Регистрация внешнего отчёта в БСП (без команд)

Добавляет в `ObjectModule.bsl` внешнего отчёта функцию `СведенияОВнешнейОбработке()` **без** таблицы `Команды`.

## Важно

- У `ExternalReport` **нет** команд в метаданных — только СКД и общие формы отчёта.
- Блок `РегистрационныеДанные.Команды.Добавить()` в ERF **не добавлять**, если пользователь явно не попросил.
- Если в ERF уже есть `Команды.Добавить()` — **скорее всего ошибка** (копипаст с EPF). Сообщи пользователю и предложи удалить.
- Для **обработок** (EPF) — skill `/epf-bsp-init` (там команды нужны).

## Usage

```
/erf-bsp-init <ReportName> [Version]
```

| Параметр   | Обязательный | По умолчанию | Описание                                      |
|------------|:------------:|--------------|-----------------------------------------------|
| ReportName | да           | —            | Имя отчёта (`energy_…` в `src/energy_….xml`)    |
| Version    | нет          | из `VERSION` | Версия для `РегистрационныеДанные.Версия`     |
| SrcDir     | нет          | `src`        | Каталог исходников в `build/<Имя>/`           |

## Шаблон

Версию синхронизировать с `build/<Имя>/VERSION` и синонимом (`… vX.Y.Z`).

```bsl
#Область ПрограммныйИнтерфейс

// Возвращает сведения для регистрации отчёта в подсистеме БСП "Дополнительные отчеты и обработки".
//
// Возвращаемое значение:
//  Структура - см. ДополнительныеОтчетыИОбработки.СведенияОВнешнейОбработке.
Функция СведенияОВнешнейОбработке() Экспорт
	
	МетаданныеОтчета = Метаданные();
	Синоним = МетаданныеОтчета.Синоним;
	Синоним = ?(ЗначениеЗаполнено(Синоним), Синоним, МетаданныеОтчета.Имя);
	
	РегистрационныеДанные = ДополнительныеОтчетыИОбработки.СведенияОВнешнейОбработке(
		СтандартныеПодсистемыСервер.ВерсияБиблиотеки());
	РегистрационныеДанные.Вид = ДополнительныеОтчетыИОбработкиКлиентСервер.ВидОбработкиДополнительныйОтчет();
	РегистрационныеДанные.Наименование = Синоним;
	РегистрационныеДанные.Версия = "{{Version}}";
	РегистрационныеДанные.БезопасныйРежим = Истина;
	РегистрационныеДанные.Информация =
		ДополнительныеОтчетыИОбработкиКлиентСервер.ВидОбработкиДополнительныйОтчет() + " " + Синоним;
	
	Возврат РегистрационныеДанные;
	
КонецФункции

#КонецОбласти
```

## Инструкции

1. Найди `ObjectModule.bsl`: `build/<Папка>/src/<ReportName>/Ext/ObjectModule.bsl`
2. Если `СведенияОВнешнейОбработке` уже есть:
   - есть `Команды.Добавить()` → предупреди об ошибке, убери блок по запросу пользователя;
   - без команд → не дублируй, при необходимости обнови только версию/поля.
3. Если функции нет — вставь шаблон в `#Область ПрограммныйИнтерфейс`.
4. **Не** вызывать `/epf-bsp-add-command` для ERF.
