# Навыки

Два слоя. Для новой работы нужен верхний.

## Слой comol — им пользоваться

Источник: [comol/ai_rules_1c](https://github.com/comol/ai_rules_1c), в харнесе закреплен коммит `1a19311` (28.10.2026). Правила по запросу лежат рядом, в `rules\`.

Метаданные (справочник, документ, форма, роль, СКД, макет, расширение, база) — один навык `1c-metadata-manage`. Он сам вызывает скрипт в `1c-metadata-manage/tools\`.

Остальные папки этого слоя — маршруты, не вторые копии того же скрипта: где искать код (`1c-code-search`, `1c-impact`, `1c-meta-info`), чем проверить (`1c-validate`), живая база (`1c-live-ib`), интерфейс (`1c-qa-testing`), справка (`1c-platform-help`, `mcp-1c-tools`).

Свои добавления харнеса, не из comol: `1c-delegation`, `1c-pipeline`.

## Плоские папки — старый комплект

`form-*`, `cfe-*`, `cf-*`, `db-*`, `epf-*`, `erf-*`, `meta-*`, `mxl-*`, `skd-*`, `role-*`, `subsystem-*`, `openspec-*` — те же команды, разложенные по одной папке. Скрипт с тем же именем уже есть внутри `1c-metadata-manage/tools\`, и это не одна и та же копия байт в байт.

Новую правку вести через `1c-metadata-manage`. Плоскую папку открывать, только если задача прямо назвала этот навык.
