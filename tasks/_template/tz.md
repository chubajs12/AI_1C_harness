## Definition of Done

Задача сдана, когда отмечено все применимое; пропущенный пункт — с причиной.

- [ ] Критерии приемки из `brief.md` — каждый с доказательством (снимок, данные запросом MCP 1С, отчет Vanessa)
- [ ] Гейты (`AGENTS.md` п. 3): синтаксис каждого модуля, тексты запросов на живой базе, формы, UUID, БСП / v8std
- [ ] Новые объекты метаданных — навыком, XML проверен (`meta-validate` / `cfe-validate`)
- [ ] Версия: `Configuration.xml`, `VERSION`, имя CFE; Full Load → CheckModules (тонкий, веб, сервер, мобильный) → UpdateDB
- [ ] Свежий CFE выгружен из базы, прошлый — в `old/`
- [ ] Vanessa: новая или обновленная фича под изменение; прогон затронутого блока с вайпа до fail=0
- [ ] Каждая исправленная ошибка — регрессионный тест (шаг фичи или проверка MCP 1С), который падал до исправления
- [ ] Свои клиенты тестирования закрыты штатно, свои спящие сеансы 1С завершены
- [ ] Разбор соответствия: каждое требование — выполнено / частично / нет; «нет» — не сдавать
- [ ] Коммит и тег версии (сырцы; настройки — если менялись правила или скрипты), строка в `docs/changelog.md`
- [ ] Выпуск в боевую (если есть): дельта к свежей боевой (`docs/05`), после переноса — сверка, 0 расхождений
- [ ] `log.md`: итоги тестов таблицей, ссылки на CFE и документы, следующий шаг
