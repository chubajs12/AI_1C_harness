# Закрытие задачи: отчёт пользователю

**Единственный канон** текста финала. Копии в Project store / Cursor Context **не** вести — только ссылка на этот файл.

Перед заполнением: `rules/verify-before-reply.md`, цикл — `docs/agent-workflow.md`, DoD — `tasks/…/tz.md` и `brief.md`.

## Когда можно закрывать

- DoD закрыт **или** остаток явно «частично / нет» с доказательством после осмысленных попыток дожать в области задачи.
- Утверждения опираются на арtefact (лог Конфигуратора, JSON, CFE/EPF/DOCX, `/health`, отчёт Vanessa, `tasks/*/log.md`). Vanessa/PMI — pass/fail **только из файлов отчётов**.
- **Не** «готово» без таблицы сверки; **не** BLOCKER без повтора/fix, который агент мог выполнить сам.

## После отчёта в чат — `log.md`

```text
FINISHED — <ГГГГ-ММ-ДД ЧЧ:ММ>, DoD закрыт: <одна фраза>.
```

Отмена: `FINISHED — отменено пользователем: <цитата>`.

## Антипаттерны

- «Тесты зелёные» без цитаты из отчёта.
- Пересказ запроса вместо checklist.
- FINISHED в log до отчёта пользователю в этом формате (кроме явной отмены).
- Благодарности, список tools без секции «Контекст», секции-заглушки без содержания.
