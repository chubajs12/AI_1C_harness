# Реестр MCP и сервисов контура

Ведет владелец инфраструктуры; правки — через MR. Адреса отсюда агенты берут в `project.env`. Версия — тег с
номером или digest образа; `latest` и `*-beta` в реестр не вносятся. Обновление — новая версия на соседнем порту →
проверка → переключение → строка обновлена (дата, версия), старая версия остановлена.
