# MCP и шина: харнес и проект

Источник истины общих настроек линии — репозиторий `https://github.com/chubajs12/AI_1C_harness`, локально `F:\AI_1C\harness`.

Проект (energy, dolea и остальные) эту базу не копирует. В папке проекта остаются свое: `PROJECT.md`, `config/project.env.local`, задачи, индексы. В правилах проекта — ссылка на путь харнеса, не второй полный текст.

Канон портов и кто где живет: [mcp-and-ports.md](mcp-and-ports.md). Числа — только в `config/ports-registry.yaml` (зеркало `config/ports-registry.json`). Подключение проекта: [00_Подключить_проект.md](00_Подключить_проект.md). Инструменты: [02_MCP.md](02_MCP.md).

В этот файл порты не дублируются.

## Шина чатов — не порты

Договоренности между Project-чатами: [../coordination/README.md](../coordination/README.md), ящики `coordination/inbox/*.jsonl`.

Шина не задает порты Vanessa, code-index, MCP 1С и не заменяет реестр. Сообщение в inbox может сослаться на уже записанный порт. Новое число порта в шину и в проект не выдумывают.
